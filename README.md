## 🧭 Overview

**Sleep-Quality-Prediction-Web-App** is a developer-friendly web application that integrates machine learning with a clean Flask interface to predict sleep quality in real-time. It handles data preprocessing, model inference, and user interaction in a seamless, intuitive workflow.

### **Why Use This Project?**
This web app simplifies the deployment of sleep prediction models:

- 🧩 **Data Preprocessing** — Converts raw survey data into clean, model-ready features.  
- 🚀 **Real-time API** — Fast and efficient prediction engine using Flask.  
- 🌐 **Responsive UI** — Works smoothly across devices.  
- 🔧 **Modular Architecture** — Easy to maintain, extend, and integrate.  
- 📦 **Straightforward Setup** — All dependencies managed via `requirements.txt`.

## 🚀 Getting Started

### 🔑 Prerequisites
You must have:

- **Python**
- **Pip** (Python package manager)

---

### ⚙️ Installation

Clone and install the project:

1. **Clone the repository:**
   ```sh
   git clone https://github.com/I-jidd/Sleep-Quality-Prediction-Web-App
2. **Navigate to the project directory**
   ```sh
   cd Sleep-Quality-Prediction-Web-App
3. **Install the dependencies**
   ```sh
   pip install -r requiremnents.txt
**Usage**

Run the application using:
```sh
python app.py
```

The Flask web server will start, making the Sleep Quality Prediction app available locally.
